# 💰 Sistema de Gestión de Gastos

Aplicación de escritorio desarrollada en **C#**, **WPF (.NET Framework)** y **SQL Server**, diseñada para administrar gastos personales mediante un sistema moderno e intuitivo. El proyecto incorpora autenticación de usuarios, dashboard interactivo con gráficos estadísticos, gestión de categorías, generación de reportes y exportación a PDF, aplicando una arquitectura organizada y buenas prácticas de desarrollo.

---

## 🏷️ Tecnologías y Herramientas

* C#
* WPF (.NET Framework)
* XAML
* SQL Server
* ADO.NET
* LiveCharts
* PDFSharp
* Git
* GitHub

## 🗄️ Base de Datos

El sistema utiliza **SQL Server** como motor de base de datos.

### Base de datos

```sql
db_GestionGastos
```

### Tablas principales

* tb_usuarios
* tb_categoria
* tb_gastos

### Procedimientos almacenados

* SP_LOGIN
* SP_LISTAR_GASTOS
* SP_LISTAR_CATEGORIAS
* SP_INSERTAR_GASTO
* SP_EDITAR_GASTO
* SP_ELIMINAR_GASTO
* SP_GRAFICO_CATEGORIAS
* SP_REPORTE_GASTOS_MES
