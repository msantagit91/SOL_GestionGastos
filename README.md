# SOL_GestionGastos

Aplicación de escritorio desarrollada en WPF (.NET), SQL Server y C# para la gestión de gastos personales.

## Características

* Inicio de sesión de usuarios.
* Registro de usuarios.
* Gestión de gastos.
* Gestión de categorías.
* Dashboard interactivo.
* Gráfico circular con LiveCharts.
* Reportes mensuales.
* Exportación de reportes a PDF.
* Filtrado de información por usuario.
* Arquitectura por capas.
* Uso de Stored Procedures.

## Tecnologías utilizadas

* C#
* WPF
* XAML
* SQL Server
* ADO.NET
* LiveCharts
* PDFSharp
* Git
* GitHub

## Base de Datos

Nombre de la base de datos:

```sql
db_GestionGastos
```

Tablas principales:

* tb_usuarios
* tb_gastos
* tb_categoria

## Funcionalidades principales

### Dashboard

* Visualización de gastos por categoría.
* Gráfico circular alimentado desde SQL Server.
* Colores neón personalizados.

### Gastos

* Registro de gastos.
* Consulta de gastos.
* Asociación de gastos a categorías.
* Asociación de gastos al usuario autenticado.

### Categorías

* Creación de categorías personalizadas.
* Carga dinámica en el formulario de gastos.

### Reportes

* Reporte de gastos del mes actual.
* Exportación de información a PDF.
